# 口径、映射与格式约定

## 一、检查结论三档

| 结论 | 判定标准 |
|---|---|
| **符合** | 所需资料齐备且无异常 |
| **部分符合** | 资料齐备（或部分齐备），但存在瑕疵或差异待处理 |
| **不符合** | 关键资料缺失，或存在重大差异 |

实务经验：程序 2（权证）、5（财务）、9（盘点结论）几乎必然"不符合"；程序 1、3、4、6、7、8 通常"部分符合"或"符合"。

差异性质与结论的对应：**核算差错 / 管理瑕疵 → 部分符合**；**重大权属问题 / 关键资料缺失 → 不符合**。

## 二、正文表述规范（V1–V5 完整正反例）

**覆盖范围**：V1–V5 适用于**全部 5 张工作表的所有单元格文本**（检查程序表／资料清单／资产台账核对／核查发现与整改建议／编制说明），**不限于业务明细单元格**——表底说明行、编制说明整段、头部「检查对象／资料范围／检查依据」、备注与检查意见栏，一律照卡。大段叙述性文字尤其容易漏，逐句写完要回头核一遍。

**唯二例外**：「资料清单」的「资料名称」（写文件名）与「文件类型」（写类别名）两列**不卡 V3、不卡 V5**；其余 V1/V2/V4 照跑。另：表4「涉及资产」列按 V2 的例外条款处理（见 V2 小节末），不走全称＋行号。

**不构成豁免的说明**：本文件第四节的列映射表、`checktable.py` 的列号参数属文档内导航／脚本参数，不是底稿正文，因此不受本节限制——但这**不意味着**底稿里任何单元格可以豁免。

判断标准一句话：**读者只看这一句，能不能找到具体哪一项资产、哪一份文件？**

### V1　禁止用台账列字母指代字段

台账 30 列的列字母只在本文件的映射表与脚本参数里使用，写进正文一律换成字段中文名。

- ✗ `台账 O 列全为 -`
- ✓ `台账「资产账面价值（万元）」栏全为 -`
- ✗ `P 列记"无产权证"、Q 列为空`
- ✓ `台账「权证办理」栏记载「无产权证」，「不动产权证号」栏为空`
- ✗ `"租金"三列取台账应收/已收/未交租金`
- ✓ `「应收租金（元）」「已收租金（元）」「未交租金（元）」三栏取台账同名三栏`

### V2　禁止用简称指代资产

资产一律写台账「资产名称」栏原文，首次出现必须带行号／序号定位。

- ✗ `41号台账未登记土地`
- ✓ `台账中「新都区圣谕亭巷41号」一行（第 56 行／序号 151）未登记土地`
- ✗ `35号2条台账共用一本证`
- ✓ `台账中「圣谕亭巷35号8栋1单元5层9号」（第 3112 行／序号 6077）与「圣谕亭巷35号8栋2单元1层1号」（第 3113 行／序号 6078）两行共用证号 川（2018）新都区不动产权第0031166号`
- ✗ `潮玩4条资产面积全对`
- ✓ `潮玩公园商业用房1号、2号、3号、6号标的（房产表第 2330～2333 行／序号 3471～3474）四行面积全部核对一致`

**例外：表4「涉及资产」列**。该列每条发现都要填一遍，若每行都写「全称＋（房产表第 N 行／序号 X）」，10 余行重复会把版面压垮、反而看不清。该列只写「坐落＋业态」简称，行号定位由表1「检查对象」与表3 说明承担；`verify_checktable.py` 对该列另设列级检查，命中 `第 N 行`／`序号 N`／`房产表`／`土地表` 即 `FAIL`。

- ✗ `「圣谕亭商铺新都区圣谕亭巷41号」（房产表第 56 行／序号 151）`
- ✓ `圣谕亭巷41号商铺`

### V3　禁止用代称指代文件

"合同""评估""测绘""决议"只是资料类别，不是文件。每份文件至少给到《名称》＋编号，能补日期／页数就补；确实未载明的写"未载明"。

- ✗ `未提供评估报告`
- ✓ `未提供《房地产咨询估价报告》（川中誉华房估咨字〔2025〕第05012号，2025-05-06，34 页）`
- ✗ `合同、测绘、评估均已取得`
- ✓ `已取得《曾红兵房屋租赁合同》（2023-10-08，664.41 ㎡，商业/餐饮）、《房屋面积实测报告》（2栋 S20170030、3栋 S20160042）、《房地产咨询估价报告》（川天一房评咨字〔2023〕第058号）`
- ✗ `形成主体：评估机构`
- ✓ `形成主体：四川中誉华房地产估价有限公司（见报告封面「估价机构」栏）`

### V4　禁止含糊指代

- ✗ `该资产面积与测绘一致`
- ✓ `「潮玩公园商业用房3号标的」（房产表第 2332 行／序号 3473）台账面积 334.71 ㎡，与《潮玩公园商业用房标地测绘报告（1-3号标的）》（JD2025-J0307）3# 308.81 ㎡＋4# 25.90 ㎡ 合计一致`
- ✗ `台账 1 条对应测绘 2 栋`
- ✓ `该行对应测绘报告 3 栋、4 栋两条记录`
- ✗ `上述资料未提供`
- ✓ `《不动产登记信息查询结果》未提供`

### V5　禁止把台账表名写成英文 `sheet`

主台账是 xlsx，内部两张工作表在本项目里就叫**「房产表」「土地表」**。`sheet`／`Sheet1`／`房产 sheet`／`土地 sheet` 一律不许出现在单元格里；也不许用「台账 1」「台账 2」代称，读者无法据此判断是哪张表。

- ✗ `土地 sheet 共 15 行`
- ✓ `土地表共 15 行`
- ✗ `房屋与土地分列两个 sheet`
- ✓ `房屋与土地分列房产表、土地表两张表`
- ✗ `房产 sheet 第 56 行／序号 151`
- ✓ `房产表第 56 行／序号 151`

|---|---|

| `编制说明!B8` | 文件代称 |

## 三、差异类型分类表（表3 第20列、表4 第3列）

| 类型标记 | 含义 | 典型情形 |
|---|---|---|
| 权证缺失 | 无不动产权证，也无权属来源文件 | 台账记"无产权证"、证号 `-` |
| 面积差异 | 台账／权证／测绘三者面积不一致 | 差 11.06㎡、差 2,343.97㎡ |
| 权属不符 | 权利人、坐落、用途、土地性质与台账不符 | 土地证坐落「圣谕亭巷142号」≠台账记载「圣谕亭巷41号」 |
| 账实不符 | 账面价值缺失、无明细账、账外资产 | 台账「资产账面价值（万元）」栏全为 `-` |
| 差异（表4） | 面积/栋数计价口径不一致 | 台账「潮玩公园3号标的」一行对应测绘报告 3 栋、4 栋 |
| 瑕疵（表4） | 登记规范性问题 | 取得时间 1905-07-14、名称含冗余空格 |
| 风险（表4） | 可能导致损失或影响处置 | 无证影响招商抵押、闲置、第三方占用 |
| 提示（表4） | 提请关注、尚不构成问题 | 土地未在台账单列、无盘点结论报告 |

## 四、主台账字段映射（`成都香城产业发展集团有限公司8.12_副本.xlsx`）

两个工作表：**房产表**（约 3,132 行）、**土地表**（19 行）。
**表头在第 3、4 行，数据自第 5 行起**。

| 列 | 字段 | 说明 |
|---|---|---|
| A | 序号 | 流水号，**不是资产编号** |
| B/C | 管理公司所属二级公司／管理公司 | |
| D/E | 权属公司所属二级公司／权属公司 | 填"对应资产"时用 E 列 |
| F | 资产名称 | 常见冗余空格与重复词 |
| G | 项目名称 | 同一项目多行时用它聚合 |
| H | 资产面积（㎡） | 台账面积 |
| I | 具体位置 | 常见只到路名 |
| J | 是否园区内资产 | |
| K | 资产类型 | 房产／土地 |
| L | 资产业态 | 商铺／住宅／其他商服用地… |
| M | 资产取得方式 | 自建／无偿划转／公开出让… |
| N | 资产取得时间 | 常见占位值 `1905-07-13/14` |
| O | 资产账面价值（万元） | 常为 `-` |
| P | 权证办理 | `无产权证`／`有不动产权证`／`B证` |
| Q | 不动产权证号 | 常为 `-` |
| R | 资产状态 | 已出租／待出租／待招商／不可招商 |
| S | 资产使用人 | 承租方 |
| T/U | 合同开始／终止时间 | |
| V/W/X/Y | 应收／已收／未交／欠缴租金（元） | 表3 的 15/16/17 列取 V/W/X |
| Z | 欠缴租户类型 | |
| AA/AB | 闲置面积／闲置原因 | |
| AC | 备注 | 常含"…之后的租金由资管公司收缴" |

**定位方法**：逐单元格搜索标的名称关键词（如"圣谕亭""潮玩""九街"），不要只看 F 列——名称可能分散在多列。

## 五、格式约定

- 面积：保留 2 位小数；差异可为负，正值为测绘大于台账。
- 金额／面积列：`#,##0.00`，仅对数值型套用。
- 日期：**文本**写入 `YYYY-MM-DD`，不要转 datetime（否则 Excel 会按本机区域重排）。
- 单位：表3 金额列头写"（元）"，需换算的原始数据（如万元）在说明里注明。
- 合并区、列宽、行高由 `checktable.py` 统一生成，避免手调导致不一致。

## 六、命名与交付

| 项 | 规则 |
|---|---|
| 文件名 | `<标的或项目名>资产清查检查程序表.xlsx`，如 `潮玩公园资产清查检查程序表.xlsx` |
| 存放 | 与被查资料同级的项目目录（如 `C:\潮玩\`） |
| 脚本 | `_build_<简称>_checktable.py`（构建）、`_verify_<简称>_checktable.py`（校验） |
| 交付 | 用 `present_files` 呈现成品；文本小结给"结论分布＋关键数字＋主要疑点" |

**一份标的一份独立文件，绝不覆盖已有的其他标的底稿、也不改样板文件。**

## 七、"不作定性"原则

只做"客观数据提取＋比对＋标记疑点"：
- 用"资料未提供，待补""存在……情形""待核实"。
- 不用"违规""舞弊""损失"等结论性表述。
- 例外：结论列必须给三档评级，这是检查结论而非审计定性。

## 八、Windows 环境坑

- **Bash 工具不可用**（中文工作目录导致 shell 载入失败）→ 一律用 **PowerShell** 调 Python。
- 解释器：`C:\Users\<user>\.workbuddy\binaries\python\envs\default\Scripts\python.exe`（需含 `openpyxl`、`pypdfium2`；缺则 `…\Scripts\pip.exe install openpyxl pypdfium2`）。
- 中文路径经**环境变量**传入 Python（`$env:P="C:\…"` + `os.environ['P']`），避免引号被剥离。
- PowerShell 命令里避免出现 `%…%` 形态（会被安全策略当作 cmd 变量语法拦截）→ 改用 f-string / 拼接；含 `%` 的代码写进 `.py` 文件再执行即可。
- 同名嵌套目录常见（如 `新都区圣谕亭巷41号\新都区圣谕亭巷41号\`），用 `Get-ChildItem -Recurse` 先确认实际层级。
- 文件名可能含不换行空格 `\xa0` → 用 `os.listdir` 精确匹配，不要手打路径。
- 扫描件无文字层 → `pdf_probe.py render` 渲染 PNG 后读图；图片有每轮读取预算，只读必要页（评估报告常 20MB+、30 页以上）。
- 大文件（如 24.8MB/34 页评估报告）不要整本渲染，只渲染封面＋关键页。
