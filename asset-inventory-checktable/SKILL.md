# 资产清查检查程序表

## 概述

以《资产清查程序表》9 项程序为纲，对指定标的开展**资产清查**（查资产本身：权属、测绘面积、财务账面、权属风险），产出 5 张表的 Excel 底稿。所有标的共用**同一结构**（照 `新都街道移交资料检查程序表.xlsx`），保证多份底稿格式完全一致、结论可横向对比。

**核心原则**：只做"客观数据提取＋比对＋标记疑点"，**不做审计定性**（结论列的三档评级属于检查结论，不是定性）；一份标的一份独立文件，**绝不覆盖样板或既有成品**。

## 何时使用

- 用户要求"以这个程序表清算 / 清查 / 检查 XXX（某房产或土地标的）""补资产清查底稿""做移交资料检查程序表"。
- 典型输入：① 主台账 `成都香城产业发展集团有限公司8.12_副本.xlsx`（房产表 / 土地表）；② 标的资料目录（权证、合同、测绘报告、评估报告、招租/决议纪要、竞价结果等 PDF）。
- 与"租金收缴专项核查"区分：那个查**租金**（应收/已收/欠缴），本技能查**资产**（权属/面积/账面/风险）。

## 正文表述规范（写进单元格的文字必须遵守）

**总纲**：读者只看这一句，能不能找到具体哪一项资产、哪一份文件？答不出就是没写清。

| 编号     | 禁忌         | ✗ 反例                       | ✓ 正例                                                                                                 |
| ------ | ---------- | -------------------------- | ---------------------------------------------------------------------------------------------------- |
| **V1** | 用台账列字母指代字段 | `台账 O 列全为 -`               | `台账「资产账面价值（万元）」栏全为 -`                                                                                |
| **V2** | 用简称指代资产    | `41号台账未登记土地`               | `台账中「新都区圣谕亭巷41号」一行（第 56 行／序号 151）未登记土地`                                                              |
| **V3** | 用代称指代文件    | `未提供评估报告`                  | `未提供《房地产咨询估价报告》（川中誉华房估咨字〔2025〕第05012号，2025-05-06，34 页）`                                              |
| **V4** | 含糊指代、无法定位  | `该资产面积一致`／`台账 1 条对应测绘 2 栋` | `「潮玩公园商业用房3号标的」（房产表第 2332 行／序号 3473）台账面积 334.71 ㎡ 与测绘 3# 308.81＋4# 25.90 合计一致`／`该行对应测绘报告 3#、4# 两条记录` |
| **V5** | 台账表名写成英文 `sheet` | `房产 sheet 共 3,132 行`／`房屋与土地分列两个 sheet` | `房产表共 3,132 行`／`房屋与土地分列房产表、土地表两张表` |

五条强制格式：

1. **引用资产** → `台账中「<台账"资产名称"栏原文>」一行（第 N 行／序号 X）`。首次出现必带行号定位；后文可称「<全称>」，但不得缩成"41号""35号2条"。
   **例外**：表4《核查发现与整改建议》的「涉及资产」列不写全称＋行号，只写「坐落＋业态」简称（如 `圣谕亭巷41号商铺`）——该列 10 余行重复全称会压垮版面，定位由表1「检查对象」与表3 说明承担。
2. **引用文件** → `《<资料清单"资料名称"栏原文>》（<编号>，<日期>，<页数> 页）`。编号／日期／页数缺哪个就写"未载明"，不许只留裸名。
3. **引用台账字段** → `台账「<字段中文名>」栏`，永不用列字母。
4. **引用台账表名** → 一律写「房产表」「土地表」，不写 `sheet`、不写英文表名（`房产 sheet`／`土地 sheet`／`Sheet1` 均属违规），也不用「台账 1」「台账 2」代称。
5. **严禁**：`该资产`、`上述资料`、`前述文件`、`N 号台账`、`N 号 M 条`。

**适用范围**：本节约束**全部 5 张工作表的所有单元格文本**——检查程序表、资料清单、资产台账核对、核查发现与整改建议、编制说明。**不限于业务明细单元格**：表底说明行、编制说明的大段文字、备注与检查意见栏、头部「检查对象／资料范围」等同样强制执行。表 1「执行内容」「应取证资料」引用的《资产清查程序表》原文若含违规表述，按最小必要原则改写（见 `references/procedures.md` 的改写注记），**不作整列豁免**。

`verify_checktable.py` 对 5 张表**逐格**做 V1–V5 体检，命中即 `FAIL`；例外仅两处：「资料清单」的「资料名称」「文件类型」两列不卡 V3（写的是文件名／类别名，不是引用），亦不卡 V5（文件名本身可能带 `sheet`）；表4「涉及资产」列不卡 V2，但另设列级检查——命中 `第 N 行`／`序号 N`／`房产表`／`土地表` 即 `FAIL`。

样板 `新都街道移交资料检查程序表.xlsx` 的 `检查程序表!G8`、`资产台账核对!X3`、`核查发现与整改建议!E7`、`编制说明!B8` 是反例，**不可照抄**。

## 工作流

### 阶段 1 — 定位资产与资料

1. 在主台账的**房产表**、**土地表**两张工作表**逐单元格**搜索标的名称关键词（如"圣谕亭""潮玩""九街"）。表头在第 3、4 行，数据自第 5 行起。
2. 完整导出命中行的**全部列值**（共 30 列：序号、权属公司、面积、位置、取得方式、权证办理、状态、使用人、合同起止、应收/已收/未交租金、闲置、备注等），重点记：序号、权属公司、面积、位置、取得方式/时间、权证办理/证号、状态、使用人、合同起止、应收/已收/未交租金、闲置、备注。列映射见 `references/conventions.md`。
3. 用 `Get-ChildItem -Recurse` 定位标的资料目录（注意**同名嵌套目录**），记录每个文件。已清查标的一览见 `references/target-registry.md`。
4. **确认范围**：用 AskUserQuestion 与用户确认 ①清查哪些资产（可能含同项目的"登记但未出租"行）②资料清单涵盖范围。不要自行扩大或缩小。

### 阶段 2 — 读取资料

1. 先跑 `scripts/pdf_probe.py meta <目录>`，拿到每份 PDF 的**页数**与**有无文字层**。
2. 有文字层 → `scripts/pdf_probe.py text <pdf> <out.txt>`，然后**读那个 txt 文件**（控制台会乱码中文）。
3. 扫描件 → `scripts/pdf_probe.py render <pdf> <outdir> 2.5`（≈180 DPI），再逐页读图。大文件（20MB+、30 页以上）**只渲染封面＋关键页**。
4. 提取字段：权证（权利人/坐落/用途/土地性质/面积/期限）、测绘（编号/出具单位/资质/日期/栋层/各房名面积/备注）、合同（承租方/面积/租期/租金/递增/免租/付款）、评估（编号/时点/单价/年租金）、纪要（次数/日期/票数/结论）。

### 阶段 3 — 面积比对

1. 建立"台账面积 ↔ 测绘房名/栋号"的对应关系。一个标的可能对应**多个栋/房名**（如台账「潮玩公园3号标的」一行，对应测绘报告 3 栋、4 栋两条记录，308.81+25.90=334.71㎡），务必写清对应关系而不是只写"1 条对 2 栋"。
2. 算 **面积差异 = 测绘参考面积 − 台账面积**（正值为测绘大于台账）。
3. 无测绘成果的资产，差异填 `—`，并在表3 差异类型里注明"无测绘成果"。
4. 权证载面积缺失时，明确写"仅完成台账面积与测绘面积两方比对（无不动产权证载面积可用）"。

### 阶段 4 — 组装 spec 并生成底稿

1. 按 `scripts/checktable.py` 的 schema 写 `spec.json`（行是**按列顺序的数组**，见脚本头部 docstring 或 `python checktable.py --example`）。
2. 运行 `python checktable.py spec.json` 生成 `<标的>资产清查检查程序表.xlsx`。
3. 5 张表内容要点：
   - **检查程序表**：B~E 列照抄 9 项程序（`references/procedures.md` 有原文），F 写"资料提供情况"、G 写"检查发现"、H 判"符合/部分符合/不符合"。合计行由脚本自动统计。原文中程序 6「应取证资料」、程序 8「执行内容」各 1 处已按 V1–V5 作最小改写，**照抄改写后的版本**（见该文件注记），不得自行增删。
   - **资料清单**：逐份列示，含页数、形成主体、日期、摘要、对应程序、是否扫描件。
   - **资产台账核对**：每项资产一行，24 列（含租金三列、测绘参考面积、面积差异、差异类型/原因、取证资料清单、检查意见）。
   - **核查发现与整改建议**：10~13 条，类型限定 `缺项/差异/瑕疵/风险/提示`，每条给可执行的整改建议；「涉及资产」列写「坐落＋业态」简称，不重复全称与行号。
   - **编制说明**：固定 8 行（依据/对象/资产/方法/口径/结论/来源/声明）。
4. 详细列序、合并区、口径见 `references/workbook-structure.md`。

### 阶段 5 — 校验

运行 `python verify_checktable.py <xlsx> --keywords <本项目不应出现的旧项目名>`，确认：

- 5 张表齐备、表头列数 8/10/24/6/2；
- 结论列仅取三档，合计行统计与逐条一致；
- **面积差异 = 测绘参考面积 − 台账面积**（数值行全部通过）；
- 金额/面积列格式 `#,##0.00`；
- **无 V1–V5 表述违规**（列字母／资产简称／文件代称／含糊指代／台账表名写成 `sheet`；**全表逐格**，含表底说明行与编制说明大段文字）；
- 表4「涉及资产」列无行号／序号／表名（列级检查单独报错）；
- 无残留他项目表述。

`FAIL>0` 必须修到 0 再交付。

### 阶段 6 — 交付

用 `present_files` 呈现成品（首个条目为新文件）。文本小结给：**结论分布（符合/部分符合/不符合）＋资产范围与面积核对结果＋本轮新读出的关键事实＋主要疑点**。不要长篇复述表格内容。

## 关键规则

| 项目     | 约定                                         |
| ------ | ------------------------------------------ |
| 结论口径   | 符合＝资料齐备且无异常；部分符合＝有瑕疵或差异待处理；不符合＝关键资料缺失或重大差异 |
| 差异类型   | 表3/表4 只用：权证缺失／面积差异／权属不符／账实不符／缺项／瑕疵／风险／提示   |
| 面积差异   | = 测绘参考面积 − 台账面积；无测绘填 `—`                   |
| 取得时间   | 按台账原文以**文本**写入（如 `1905-07-14`），不转 datetime |
| 金额面积格式 | `#,##0.00`，仅对数值型套用                         |
| 定性     | 不做审计定性，用"资料未提供，待补""存在…情形""待核实"             |
| 分文件    | 一标的一份独立底稿；绝不覆盖样板与既有成品                      |
| 台账表名   | 一律写「房产表」「土地表」，不写 `sheet`、不写英文表名         |
| 表4 涉及资产 | 用「坐落＋业态」简称（如 `圣谕亭巷41号商铺`），不带表名／行号／序号 |
| 命名     | `<标的或项目名>资产清查检查程序表.xlsx`                   |

## 资源

- `scripts/checktable.py` — 主构建器。`spec.json` → 5 表底稿；`--template out.xlsx` 出空白模板；`--example` 打印示例 spec。列宽/合并/底纹/合计统计全自动。
- `scripts/verify_checktable.py` — 成品校验（表齐备、列数、三档结论、合计一致、面积差异算式、金额格式、残留关键词、**全表逐格 V1–V5 表述体检**，含表4「涉及资产」列级检查）。`FAIL>0` 退出码 1；`--no-wording` 可临时跳过体检（不推荐）。
- `scripts/pdf_probe.py` — PDF 探针：`meta`（页数/文字层）、`render`（渲染 PNG）、`text`（导出文字层到 txt）。
- `references/procedures.md` — 9 项程序原文 + 每个程序的 F/G/H 填法 + 实测结论分布。
- `references/workbook-structure.md` — 5 张表精确结构（表头顺序、合并区、合计行、说明行、格式）。
- `references/conventions.md` — 三档口径、差异类型分类表、主台账 A~AC 列映射、命名与格式、Windows 环境坑。
- `references/target-registry.md` — 已清查标的登记表（新都街道/潮玩公园/圣谕亭巷41号/九街），含台账行号、面积、权证、测绘编号与关键差异。
- `assets/checktable-template.xlsx` — 空白 5 表模板（表头/合并/列宽已就位）。
- `assets/example-filled.xlsx` — 已完成样例（潮玩公园，4 项资产），可作填写参照。

## 环境与常见坑

- **Bash 工具不可用**（中文工作目录导致 shell 载入失败）→ 一律用 **PowerShell** 调 Python。
- 解释器：`C:\Users\<user>\.workbuddy\binaries\python\envs\default\Scripts\python.exe`；缺库则 `…\Scripts\pip.exe install openpyxl pypdfium2`。
- 中文路径经**环境变量**传入（`$env:P="C:\…"` + `os.environ['P']`）。
- PowerShell 命令行里避免 `%…%` 形态（会被安全策略当作 cmd 变量语法拦截）；含 `%` 的代码写进 `.py` 文件再执行。
- 扫描件无文字层 → 渲染 PNG 后读图；图片有每轮读取预算，只读必要页。
- 同一标的多行（如"主标的＋登记但未出租"行）时要分别列示，不要合并成一行。
