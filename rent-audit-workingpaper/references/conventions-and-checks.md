# 口径细则与校验清单

> 本文件的列映射片段（如"V 列""AA 列"）**仅供填表定位使用**；写进底稿正文、备注、疑点清单一律改用**字段中文名**（见 `SKILL.md`「正文表述规范 V1–V4」）。

## 一、欠租口径（核心约定）

**"台账原值 + 到期口径并列"**：

- **应收租金（元）／已收租金（元）／未交租金（元）／欠缴租金（元）** ＝ 主台账同名四栏**原值**，逐字照录，**不修正**。
- **欠租金额／欠租起始月份／欠租时长** ＝ 按合同付款计划推算的**"截至基准日已到期未收"**口径。

### 语义区分

| 字段 | 含义 |
|---|---|
| 未交租金（元） | **未到期**部分（应付日尚未到） |
| 欠缴租金（元） | **已到期未收**（按台账口径） |
| 欠租金额 | 审计按合同口径重算的**已到期未收**；可能与「欠缴租金（元）」不一致 |

### 「应收租金（元）」与「合同测算累计应收租金」的关系

两者是**两个来源的比对指标，不强制相等**：

| 情形 | 处理 |
|---|---|
| 数值一致 | 备注写"台账应收与合同测算一致"，无需差异登记 |
| 数值不一致 | **属对账差异**：在《合同与财务对账差异明细表》登记一行，「对应台账序号」填该行台账序号，「差异类型」勾"金额差异"并在括号注明"台账与合同测算差异"，「差异简要描述」写清差额与原因（待凭证核实） |
| 一方为空／非数值 | 备注与疑点清单各记一条（缺失方须写明） |

**铁律**：**不得为追求相等而改动测算数据**。差异是要被登记与解释的，不是要被抹平的。

### 到期口径判定

对合同的每一期：若 **应付日 ≤ 基准日** 且该期**未足额收到**，则其未收部分计入"已到期未收"。

- 先付后用（如"上期到期前 30 日 / 20 日前支付下期"）会使**下一期在基准日前即已到期**，须一并计入。
- 若台账「欠缴租金（元）」与到期口径「欠租金额」不一致，**两者都要保留**：前者记原值，后者记重算值，并在「备注」写明差异原因（如"台账未含第 X 期"），标注"待凭证核实，不作定性"。

## 二、序号规则

- 底稿台账「序号」取**标的号或合同组号**（如潮玩公园用 1/2/3/6；九街按移交台账组号 1/2/3/4；圣谕亭用 1/2/3），与用户确认后统一。
- **不要**直接照抄主台账「序号」栏的长流水号（如 151、3455）；但**备注里必须写长序号**用于溯源。

## 三、字段填写范例

**合同约定标准**：`41元/㎡·月（不递增）`、`25元/㎡·月（第2年起逐年递增3%）`

**合同付款周期**：`按半年结算，先付后用；首期于签订合同之日起10个工作日内付清（应付日2026-05-07前），之后于上期到期20日前支付下期（期1：2026-05-01~2026-10-31；期2：2026-11-01~2027-04-30，应付日2026-10-01前）`

**资料载体类型**（四枚举，必填）：

| 取值 | 适用 | 证据效力提示 |
|---|---|---|
| `原件扫描件` | 原件扫描的 PDF | 较强，可作核对依据 |
| `复印件拍照件` | 手机拍摄的复印件 | 一般，需与原件复核 |
| `截图` | 系统/聊天截图 | 较弱，须补其他佐证 |
| `电子文档` | 原生 xlsx/pdf/docx | 强，可检索比对 |

**勾选框**：保留方框字符，勾中项用 `☑`、未勾用 `□`，并在括号内写依据：

- `是否存在租金减免`：`☑是 □否（装修免租期3个月）` 或 `□是 ☑否（合同免租期栏填"/"，无装修免租期约定）`
- `减免有无审批资料`：`☑有 □无（香城公司2024年第九次董事会决议，2024-03-04）` 或 `□有 ☑无（不适用，无租金减免）`
- `是否开展租金催收`：`□是 □否（未获取催收记录，待核实）`（**两框均不勾**，资料受限）
- `催收记录是否完整`：`□完整 □不完整（未获取催收记录，待核实）`

**备注**（建议四段式）：
`①事实（逐期测算/已到期未收）＋②差异与原因（台账值 vs 到期口径，标注"待凭证核实，不作定性"）＋③其他要素（免租期、保证金、无产权证等）＋④来源：《文件名》（编号，日期，页数）→ sheet「房产」第 N 行（资产名称）`

**财务账面类字段**（财务账面累计应收租金／账面累计实收租金／差异明细表的财务账面列）：未取得财务资料时统一填 `资料未提供，待补`；差异金额填 `待补（财务数据未取得）`，差异类型保留勾选框并注明"待补后判定"。

**疑点清单三要素**（缺一即校验 FAIL）：

| 列 | 要求 | ✗ | ✓ |
|---|---|---|---|
| 疑点（客观事实） | 只写事实，**禁用**错报/违规/虚假/舞弊/侵占/挪用 | `该合同违规减免租金` | `减免租金3个月，未见审批文件；台账「是否存在租金减免」栏记「是」` |
| 事实依据 | 必须可溯源（台账行号 或《文件名》） | `见资料` | `台账 sheet「房产」第61行（新都区YY路12号商铺）；《房屋租赁合同》（2025-03-01，22 页）第3条` |
| 核查建议 | 可执行，不能空/占位 | `请核实` | `调取该合同项下全部收款凭证与应收明细账，逐期核对应收余额，差异确认后调整台账或补登凭证。` |

## 四、四类边界场景

| 场景 | 处理规则 |
|---|---|
| **一合同对应多条台账行** | 该合同文件在《审计资料清单》**只登记 1 次**（不重复登记）；底稿台账可**按合同/标的归并成一行**，在「备注」写明对应台账的全部行号；差异明细表的「差异简要描述」完整引用《文件名》 |
| **多版合同（主合同 + 补充协议）** | **全部**入《审计资料清单》，各占一行（补充协议不算重复登记）；测算**合并全部协议**口径；「备注」写明"测算依据文件组合：《主合同》+《补充协议》"，并注明各协议生效日 |
| **台账同一标的多行重复登记** | **保留原始行不合并**（不得删行、不得合并抵消）；疑点清单新增一条，**同时写出两条行的行号**与两行的金额，建议"核实是否存在重复登记，若重复应予调整台账" |
| **账面租金数据缺失** | 资料清单对应资料项「是否提供」填 `×`，备注写 `资料未提供`；疑点清单**必须**有对应记录（事实：缺哪类资料、影响哪个字段无法核对） |

## 五、特殊租金口径

**免租期**：按合同约定区间**逐期扣减**，免租期内该期应收为 0；「是否存在租金减免」勾 `☑是` 并写免租起止与依据（合同条款页）。若免租期跨越某个付款期的一部分，按**该期实际天数**折算。

**跨年租期**：

- 按**付款周期**切分，**不按自然年**切分；
- 末尾不足一期时，按实际天数折算并在「备注」写明折算方式；
- 递增年次以**合同起始日**为锚（如起始日 2024-08-13，则 2025-08-13 起为第 2 年），不按 1 月 1 日重置。

**合同中途解除**：

- 解除日**之前**的应收照算；
- 解除日**之后**归零；
- 须取解除协议／退款凭证／终止确认书；未取得的，在备注写"解除事实待凭证核实，不作定性"，并计入疑点清单。

## 六、资料异常处理（加密 / 损坏 / 带密码）

PDF 无法解析（加密、损坏、需密码）时：

1. 《审计资料清单》**照常登记该文件**，「是否提供」填 `√`，「资料载体类型」照实填；
2. 「备注」固定写 `文件加密损坏，内容线下人工核验原件`；
3. 疑点清单新增一条：事实＝文件名 + 报错信息；依据＝资料清单第 N 行；建议＝"线下调阅原件／向被审计单位索取解密版后补充核对"；
4. **不得因此中断底稿生成**。

前置动作：`python scripts/render_pdf_pages.py <目录> --probe` 一次性拿到每份文件的 `ok / no_text_layer / encrypted / broken` 与页数。

## 七、校验清单（填写后必查）

`verify_workingpaper.py` 会自动跑，人工复核时按此对表：

1. **5 张表齐备**（含《疑点清单》；模板内置 4 张 + 脚本新建 1 张）。
2. 台账「序号」无空、无断行；序号口径与用户确认一致。
3. **差异必登记**：凡「应收租金（元）」≠「合同测算累计应收租金」的行，差异明细表都有一行「对应台账序号」＝该序号且「差异类型」含"台账"。
4. 日期为**文本**：合同起止 `YYYY-MM-DD`；欠租起始月份 `YYYY-MM`。
5. 已出租行的减免／审批／催收／催收记录四栏勾选文本齐全。
6. 「备注」含 `来源：` 与台账行号。
7. 金额列（应收/已收/未交/欠缴/合同测算/欠租金额、差异明细表 E/G）为 `#,##0.00`。
8. **资料载体类型**命中四枚举；同一文件不重复登记。
9. **疑点清单三要素**：核查建议非空、事实依据可溯源、无定性词。
10. 5 张表「核查基准日」**一致**。
11. **V1–V4 表述体检**：全 5 表逐格，含说明行与大段文本。
12. 残留关键词扫描：其它项目名/他项目承租方，命中应为 **0**。
13. 模板残留占位已清空（台账第 9–10 行的序号与勾选串、差异明细表的 A/H/J 占位）。
14. 文件可被 `openpyxl.load_workbook` 正常重新打开。

## 八、命名与交付

- **文件名**：`新都香城产业集团及下属子公司房产土地租金专项核查底稿_<标的>.xlsx`（与既有成品同目录、同前缀）。
- **绝不覆盖**模板、既有成品或原始台账；一标的/一项目**一份独立文件**。
- 用 `present_files` 呈现成品；**交付小结正文同样遵守 V1–V4**（资产写全称＋行号，文件写《文件名》，不用模糊代词）。
- 用户偏好：除非明确要求，**本轮只补底稿 Excel、不出 Word 工作小结**；对"租赁关系概括转移"等事项**仅作事实记录**、不作定性。
- **被审计单位**取主台账「权属公司」栏；写入 资料清单／程序表／欠租统计台账／差异明细表的被审计单位单元格。
