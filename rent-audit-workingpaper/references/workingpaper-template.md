# 底稿模板精确结构

模板文件：`assets/workingpaper-template.xlsx`（复制自《新都香城产业集团及下属子公司房产土地租金专项核查底稿.xlsx》）。

**表数量口径**：模板内置 **4 个 sheet**（审计资料清单 / 审计程序表 / 欠租统计台账 / 合同与财务对账差异明细表）；第 5 张《疑点清单》由 `fill_workingpaper.py` 在填写时**自动新建**，合计 **5 张**。

> 本文件的列字母（A、Q、AA…）**仅供填表定位**；写进底稿正文一律改用字段中文名（见 `SKILL.md`「正文表述规范 V1–V4」）。

统一抬头：`项目名称：尚未结清租金的租赁业务开展租金收缴专项核查`；`审计范围：成都香城产业发展集团有限公司及其下属权属公司`；`（核查基准日：2026年9月30日）`——**基准日由 `baseline` 入参决定，脚本会改写 4 张表的 A6 与疑点清单 A2**。
被审计单位写入位置：审计资料清单 `B2`、审计程序表 `B2`、欠租统计台账 `H2`、差异明细表 `C2`。

---

## 1. 审计资料清单

- `A1` 标题；`A2` 被审计单位 / `B2` 值；`A3` 项目名称；`A4` 审计目标；`A5` 审计范围；`A6` 基准日。
- 表头在第 7 行：`A序号 | B资料类别 | C资料名称 | D是否提供（√/×） | E备注 | F资料载体类型`。
- **F 列为本次新增**：`原件扫描件 / 复印件拍照件 / 截图 / 电子文档` 四选一；资料未提供（D=`×`）时可填 `—`。
- **数据行 8~18**（C 列资料名称已在模板中固定，只需填 D、E、F）：

| 行 | 类别 | 资料名称 |

## 2. 审计程序表

- `A1` 标题；`A2` 被审计单位 / `B2` 值；`A3`~`A6` 同抬头。
- 表头在第 7 行：`A序号 | B审计程序 | C执行说明 | D工作底稿索引 | E执行人员 | F日期`。
- **数据行 8~16 = 9 条程序**（B 列程序名与 C 列基础说明模板已固定）：

| 行 | 程序 | 底稿索引（建议） |
|---|---|---|
| 8 | 1 资料收集 | 《审计资料清单》 |
| 9 | 2 合同信息提取与租金测算 | 《欠租统计台账》《合同与财务对账差异明细表》 |
| 10 | 3 合同与财务账面租金核对 | 《合同与财务对账差异明细表》 |
| 11 | 4 欠租统计 | 《欠租统计台账》 |
| 12 | 5 租金减免合规核查 | 《欠租统计台账》减免与审批两栏 |
| 13 | 6 催收情况核查 | 《合同与财务对账差异明细表》差异描述 |
| 14 | 7 到期资产核查 | 《到期资产核查表》（均在租期内则不适用） |
| 15 | 8 疑点复核与取证 | 《疑点清单》，执行人员填"待人工"，日期"—" |
| 16 | 9 汇总 | （仅补底稿时填"本轮仅补底稿，暂不出审计工作小结"） |

- 程序 3、6 在 C 列**追加**（不覆盖原文）一段 `\n【本项目执行情况】…`，说明资料受限、未作定性。
- 第 17 行保留模板说明：`第1-7项，完成数据提取、测算、对账、标记疑点；第8项审计定性、专业判断由人工完成，不做定性结论。`

## 3. 欠租统计台账

- `A1` 标题；`A2` 被审计单位（值在 **H2**）；`A3`~`A6`。
- **表头在第 7 行（分组）与第 8 行（列名）**，**数据自第 9 行起**，列 `A~AH`（共 34 列）：

| 列 | 列名 | 列 | 列名 |
|---|---|---|---|
| A | 序号 | O | 合同开始时间 |
| B | 权属公司所属二级公司 | P | 合同终止时间 |
| C | 权属公司 | Q | 应收租金（元） |
| D | 资产名称 | R | 已收租金（元） |
| E | 项目名称 | S | 未交租金（元） |
| F | 资产面积（㎡） | T | 欠缴租金（元） |
| G | 具体位置 | U | 欠缴租户类型 |
| H | 是否园区内资产 | V | 合同约定标准 |
| I | 资产类型 | W | 合同付款周期 |
| J | 资产业态 | X | 合同测算累计应收租金 |
| K | 资产取得方式 | Y | 财务账面累计应收租金 |
| L | 资产状态 | Z | 账面累计实收租金 |
| M | 资产使用人 | AA | 欠租金额 |
| N | 资产使用人 | AB | 欠租起始月份 |
| | | AC | 欠租时长 |
| | | AD | 是否存在租金减免 |
| | | AE | 减免有无审批资料 |
| | | AF | 是否开展租金催收 |
| | | AG | 催收记录是否完整 |
| | | AH | 备注（合同到期占用/其他情况） |

（列字母→序号映射：A=1 … Z=26，AA=27 … AH=34）

- ⚠️ **模板残留占位**：第 9、10 行有 `A=1/2` 与 `AD~AG` 的 `□是 □否` 勾选串。数据行少于 2 行时，`fill_workingpaper.py` 会自动清空第 9–10 行的 A~AH；手工填写时须自行清除，否则校验会把残留行当作数据行。

## 4. 合同与财务对账差异明细表

- `A1` 标题；`A2` 被审计单位 / `C2` 值；`A3`~`A6`。
- 表头在第 8 行：`A序号 | B资产编号 | C租赁资产位置 | D承租方 | E合同测算累计应收租金 | F财务账面累计应收租金 | G差异金额（合同测算应收−账面应收） | H差异类型 | I差异简要描述 | J对应台账序号`；**数据自第 9 行起**。
- **J 列为本次新增**：填该差异行对应的《欠租统计台账》序号。**凡台账「应收租金（元）」≠「合同测算累计应收租金」的行，必须在此登记并在 H 列注明"台账与合同测算差异"**，否则校验 FAIL。
- H 列枚举（勾选并括号注明）：`□时间性差异 □金额差异 □缺合同 □其他`。
- 模板在 **`A11:I18` 有合并的"字段说明"区**（差异金额公式、差异类型定义、描述口径），J 列在说明区留空。填写时：
  - 若数据行不超过第 10 行 → 保留原合并区不动；
  - 若数据行延伸到第 11 行及以后 → 先 `unmerge_cells("A11:I18")`，清空 `A11`，数据填完后把字段说明**另置**到数据行下方并 `merge`（如数据到第 12 行则 `merge A14:I21`）。
- ⚠️ **残留占位**：模板第 9、10 行可能残留 `A=1/2`、`H="□时间性差异 □金额差异 □缺合同 □其他"`。`fill_workingpaper.py` 会在未提供 H 时自动清空；手工填写时须自行清除 A/H/J 三列的占位。

## 5. 疑点清单（模板中不存在，脚本自动新建）

- `A1` 标题：`<标的>租金收缴专项核查 疑点清单（客观列示，不作定性）`（`merge A1:E1`，加粗）
- `A2`：`被审计单位：<单位>    核查基准日：2026年9月30日`（`merge A2:E2`，基准日随入参）
- **第 4 行表头（5 列）**：`A序号 | B疑点（客观事实） | C事实依据 | D核查建议 | E资料充分性`
- 数据自**第 5 行**起，逐条列示疑点。
- 列宽 `A=6, B=56, C=34, D=40, E=18`，`freeze_panes="A5"`，全表加细边框、正文 `wrap_text`。
- **必填约束**：「核查建议」非空且可执行；「事实依据」须含台账行号或《文件名》；「疑点」禁用定性词（错报/违规/虚假/舞弊/侵占/挪用）。
