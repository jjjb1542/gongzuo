# 房产土地租金收缴专项核查底稿填写

## 概述

以《审计程序表》9 条程序为纲，对指定标的开展**租金收缴专项核查**（查钱：应收/已收/未交/欠缴），产出 **5 张表**的底稿 Excel。所有标的共用同一模板（`assets/workingpaper-template.xlsx`，内置 4 张）+ 脚本自动新建的《疑点清单》，合计 5 张。

**核心原则**：只做"客观数据提取 + 测算 + 标记疑点"，**不做审计定性**；一份底稿一个独立文件，**绝不覆盖模板或既有成品**。

**业务边界（与资产清查技能分工）**：

| 本技能（rent-audit-workingpaper） | 不归本技能，走 `asset-inventory-checktable` |
|---|---|
| 应收/已收/未交/欠缴租金的测算与核对 | 不动产权证、权属来源、抵押查封 |
| 合同付款周期、递增、免租期对金额的影响 | 测绘面积与台账面积差异 |
| 台账租金栏与合同测算的差异、财务账面比对 | 资产账面价值、盘点结论 |
| 租金减免、催收情况的客观记录 | 资产一档一册、移交资料完整性 |

## 何时使用

- 用户要求"审查 / 核查 / 清算 XXX（某房产或土地标的）的租金""填写 / 补全租金收缴专项核查底稿""生成某标的的审计底稿 Excel"。
- 典型输入：① 主台账 `成都香城产业发展集团有限公司8.12_副本.xlsx`（sheet `房产` / `土地`）；② 标的资料目录（合同、评估/租金报告、招采或董事会纪要、测绘报告、权属证明等 PDF）。
- **不适用**：只要权属/面积/账面价值核查、不涉及租金金额的，改用 `asset-inventory-checktable`。

## 正文表述规范（V1–V4）

**适用范围**：V1–V4 适用于**全部 5 张工作表的所有单元格文本**——审计资料清单、审计程序表、欠租统计台账、合同与财务对账差异明细表、疑点清单。**不限于业务明细格**：表底说明行、疑点清单的疑点与依据、备注与检查意见等大段文字，**同样强制执行**。

| 编号 | 禁忌 | ✗ 错误写法 | ✓ 正确写法 |
|---|---|---|---|
| **V1** | 用 Excel 列字母指代字段 | `见台账 Q 列` | `见台账「应收租金（元）」栏` |
| **V2** | 用简称指代资产 | `41号台账未登记租金` | `台账中「新都区圣谕亭巷41号」一行（第 56 行／序号 151）` |
| **V3** | 用代称指代文件 | `未提供合同、评估报告` | `未提供《房屋租赁合同》（ZC(XD)：202507-0056，2025-07-28，18 页）` |
| **V4** | 模糊代词 | `该资产`／`上述合同`／`前述资料`／`3号标的`（裸写） | 写全称 + 台账行号 |

四条强制格式：

1. **引用资产** → `台账中「<资产名称栏原文>」一行（第 N 行／序号 X）`，首次出现必带行号。
2. **引用文件** → `《<资料名称>》（<编号>，<日期>，<页数> 页）`；编号／日期／页数缺哪个就写"未载明"。主台账等 Excel 类来源用 `sheet「房产」第 N 行` 代替页码。
3. **引用台账字段** → `台账「<字段中文名>」栏`，永不用列字母。
4. **严禁**：`该资产`、`上述合同`、`前述资料`、`N 号台账`、裸写的 `N 号标的`。

**两类例外**（不是正文，是枚举/模板固定项）：① 资料清单「资料名称」列（模板固定的资料清单项）；② 差异明细表「差异类型」列（枚举勾选串）；含 `□ ☑` 勾选框字符的单元格、模板自带的"字段说明"段整体不判。

字段正反示例：

| 字段 | ✗ | ✓ |
|---|---|---|
| 备注 | `无异常，见合同` | `①事实：截至 2026-09-30 已到期应收 65,333.00 元，台账应收一致。②差异：无。③其他：无产权证。④来源：《房屋租赁合同》（2024-05-01，24 页）→ sheet「房产」第 56 行（新都区XX路41号商铺）。` |
| 疑点 | `该合同存在违规减免` | `减免租金 3 个月，未见审批文件；台账「是否存在租金减免」栏记「是」` |
| 事实依据 | `见资料` | `台账 sheet「房产」第 61 行（新都区YY路12号商铺）；《房屋租赁合同》（2025-03-01，22 页）第 3 条` |
| 核查建议 | `请核实` | `调取该合同项下全部收款凭证与应收明细账，逐期核对应收余额，差异确认后调整台账或补登凭证。` |

## 工作流

### 阶段 1 — 定位对象与台账行

1. 在主台账 `房产`、`土地` 两个 sheet **逐单元格**搜索标的名称关键词（如"圣谕亭""九街"），定位数据行。表头在第 3（分组）/ 4（列名）行，数据自第 5 行起。
2. 完整导出命中行的**全部列值**（含「备注」栏原文）。
3. **确认范围**：一个"项目"可能对应多行（同一合同覆盖多个房号）。用 AskUserQuestion 与用户确认：覆盖哪些标的、未出租/不可招商的如何处理。
4. 列映射与已定位标的见 `references/ledger-source.md`（列字母仅供填表定位，写入正文一律用字段名）。

### 阶段 2 — 收集资料并提取关键条款

1. 定位标的资料目录（可能含**同名嵌套目录**）。
2. **先跑体检**：`python render_pdf_pages.py <目录> --probe`，一次拿到每份 PDF 的 `ok / no_text_layer / encrypted / broken` 与页数——页数直接进资料清单。
3. 有文字层 → `--text` 导文字；`no_text_layer` → `--pages` 渲染 PNG（约 200 DPI）后**多模态读图**。
4. **加密 / 损坏 / 带密码**：资料清单**照常登记该文件**，「是否提供」填 `√`，「资料载体类型」照实填，备注固定写 `文件加密损坏，内容线下人工核验原件`；疑点清单加一条（事实：文件名 + 报错；建议：线下调阅原件／索取解密版）。**不得因此中断底稿生成**。
5. 提取字段（合同）：承租方、标的与**面积**、租期起止、**租金标准**、**递增方式**、**付款周期与各期应付日**、**装修免租期**、履约保证金、用途、转租约定、合同编号、签订日期。
6. 提取字段（评估报告）：机构、报告编号、评估时点、评估单价/均价、评估总价/年租金、面积。
7. 提取字段（纪要 / 测绘 / 权属）：审批结果（起始价/成交价/免租期/期限/票数）、测绘面积与分户明细、权利人/坐落/用途/面积。
8. **交叉验证**：合同单价 × 面积 × 12 是否等于评估年租金与纪要年租金。

### 阶段 3 — 合同租金测算与核对

1. **确定基准日**：由用户传入，写入 spec 的 `baseline`（默认 `2026-09-30`）；5 张表抬头与疑点清单同步。
2. 按合同付款明细**逐期测算**累计应收（含免租期扣减）。
3. **比对（不强制相等）**：「应收租金（元）」与「合同测算累计应收租金」只是**两个口径的比对指标**。数值不一致即**对账差异**，**必须**在《合同与财务对账差异明细表》登记一行（「对应台账序号」填台账序号、「差异类型」注明"台账与合同测算差异"），**不得为凑相等而改动测算数据**。
4. 已收 / 未交 / 欠缴三栏取台账原值，**逐字照录、不修正**。
5. 按基准日判定**已到期未收**：凡"应付日 ≤ 基准日且未收"的期间金额合计即为到期口径欠租。

### 阶段 4 — 填写 5 张表

复制 `assets/workingpaper-template.xlsx` 到新文件名，用 `scripts/fill_workingpaper.py` 按表填写。精确行列布局见 `references/workingpaper-template.md`。

1. **审计资料清单** — 「是否提供」填 `√/×`；「备注」**必须写清来源**；「**资料载体类型**」必填四枚举之一：`原件扫描件 / 复印件拍照件 / 截图 / 电子文档`。
2. **审计程序表** — 工作底稿索引、执行人员、日期；程序 3/6 在执行说明列**追加**`【本项目执行情况】`（资料受限、不作定性）。
3. **欠租统计台账** — 每标的一行；「应收/已收/未交/欠缴租金」四栏填**台账原值**；「欠租金额/起始月份/时长」填**到期口径**。
4. **合同与财务对账差异明细表** — 「合同测算累计应收租金」填测算值；「财务账面累计应收租金」资料未提供时填 `资料未提供，待补`；「对应台账序号」填台账序号（台账与合同测算差异必填）；「差异类型」勾选并在括号注明；「差异简要描述」含来源。数据行少于模板预留行时**清空残留占位**（A/H/J 列）。
5. **疑点清单** — 脚本自动新建第 5 张表。**5 列**：序号｜疑点（客观事实）｜事实依据｜**核查建议**｜资料充分性。每条必须：客观事实（**禁定性词**：错报/违规/虚假/舞弊/侵占/挪用）+ 可溯源事实依据（台账行号或《文件名》）+ **可执行的核查建议**。

### 阶段 5 — 校验

运行 `python verify_workingpaper.py <xlsx> --keywords <本项目不应出现的旧项目名>`，确认：

- **5 张表齐备**（含《疑点清单》）；
- 台账「应收租金」≠「合同测算累计应收租金」的每一行，差异明细表都有对应登记；
- 日期为**文本**（合同起止 `YYYY-MM-DD`，欠租起始月份 `YYYY-MM`）；
- 已出租行减免/审批/催收四栏勾选文本齐全；备注含"来源："与台账行号；
- 资料清单已填行的「资料载体类型」命中四枚举；同一文件不重复登记；
- 疑点清单「核查建议」非空、「事实依据」可溯源、「疑点」无定性词；
- 5 张表「核查基准日」一致；
- **无 V1–V4 表述违规**（全表逐格，含说明行与大段文本）；
- 无残留他项目表述。

`FAIL>0` 必须修到 0 再交付；`--no-wording` 可临时跳过表述体检（不推荐）。

### 阶段 6 — 交付

用 `present_files` 呈现成品（首个条目为新文件）。文本小结要点：范围与基准日、关键数字（应收/已收/欠租）、**台账与合同测算的差异项及其登记位置**、疑点概览。**小结正文同样遵守 V1–V4**：引用资产写全称＋行号，引用文件写《文件名》，不用模糊代词。

## 关键规则（口径与格式）

| 项目 | 约定 |
|---|---|
| 欠租口径 | **台账原值 + 到期口径并列**：「应收/已收/未交/欠缴租金」= 台账同名四栏原值；「欠租金额/起始月份/时长」= 按合同"截至基准日已到期未收" |
| 未交 / 欠缴 | 「未交租金」= 未到期；「欠缴租金」= 已到期未收 |
| 应收比对 | 「应收租金」与「合同测算累计应收租金」**不强制相等**；不等即差异，**必须登记**到差异明细表，**不得改测算数据抹平** |
| 基准日 | **入参**（spec `baseline`），默认 `2026-09-30`；5 张表抬头一致；到期口径随基准日滚动 |
| 载体类型 | `原件扫描件 / 复印件拍照件 / 截图 / 电子文档` 四选一 |
| 异常资料 | 加密/损坏照常登记 + 备注"文件加密损坏，内容线下人工核验原件" + 疑点清单留痕 |
| 来源标注 | 备注须含 `来源：《文件名》（编号，日期，页数）→ sheet「房产」第 N 行（资产名称）` |
| 金额格式 | `#,##0.00` |
| 日期 | 文本存储，`YYYY-MM-DD`（月份 `YYYY-MM`） |
| 定性 | **不做审计定性**，只客观列示并标注"待核实/待人工" |
| 分文件 | 一标的/一项目一份独立底稿；**绝不改动**模板与既有成品 |

## 环境与常见坑（Windows）

- **Bash 工具不可用**（中文工作目录导致 shell 载入失败）→ 一律用 **PowerShell** 调用 Python。
- 可用解释器（含 openpyxl / pypdfium2）：`C:\Users\<user>\.workbuddy\binaries\python\envs\default\Scripts\python.exe`；若缺库：`…\Scripts\pip.exe install openpyxl pypdfium2`。
- **中文路径**经**环境变量**传入 Python（`$env:P="C:\…\x.xlsx"` + `os.environ['P']`），避免引号被剥离 / `OSError [Errno 22]`。
- 字符串里字面量 `%` 会与 `%` 格式化冲突（`ValueError: unsupported format character`）→ 用 `.replace("{SRC}", …)` 占位符替代。
- 扫描件无文字层 → 渲染 PNG 后多模态读图（本机无 tesseract）；**图片有每轮读取预算**，分批渲染、只读必要页（评估报告常 25MB+）。
- 文件名可能含**不换行空格 `\xa0`** 等特殊字符 → 用 `os.listdir` 精确匹配。
